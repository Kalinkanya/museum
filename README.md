# museum

## Описание проекта

Задание Museum - это учебное задание, в ходе выполнения которого было необходимо сверстать landing page Лувра, добавить ему адаптивность и реализуемый через JavaScript функционал.

## Этапы работы над проектом:

- [фиксированная вёрстка](museum-fixed.md)
- [адаптивная вёрстка](museum-adaptive.md)
- [добавление JavaScript](museum-dom.md)

## Ключевые навыки:

- валидная семантическая адаптивная вёрстка
- легкоподдерживаемый читаемый код
- экспорт стилей и графики из Figma
- использование JavaScript для реализации указанного в задании функционала
